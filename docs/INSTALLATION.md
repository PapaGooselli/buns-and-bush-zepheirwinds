# Installing the modpack with Prism Launcher

## Before you start

- Install [Prism Launcher](https://prismlauncher.org/).
- Make sure you can access this private GitHub repository.
- Download the Prism Launcher instance `.zip` asset from the desired version under **Releases**.

## Import

1. Open Prism Launcher.
2. Click **Add Instance**.
3. Select **Import**.
4. Browse to and select the downloaded `.zip` file.
5. Follow the import prompts and wait for Prism to finish.
6. Start the instance.

The download is a Prism Launcher instance export, not a generic folder archive or an `.mrpack`. Import the ZIP directly through Prism's **Import** option.

## Updating

For a clean update, import the new release as a separate instance first. Back up any worlds or important local files before moving saves. Once the new instance launches correctly, you can decide whether to keep or remove the old one.

Do not copy an old `mods` folder over a new pack version unless the maintainer specifically instructs you to do so; that can leave incompatible or outdated mods behind.

## Troubleshooting

If the pack fails to launch, share the following with the maintainer:

- The exact pack release/version
- The Minecraft and NeoForge versions shown in Prism
- The error message
- The latest log or crash report

Never share account passwords, access tokens, or other credentials when asking for help.
