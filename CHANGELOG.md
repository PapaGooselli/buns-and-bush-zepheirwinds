# Changelog

All notable changes to **Buns & Bush: ZepheirWinds Edition** will be documented here.

This project uses a simple versioning convention:
- **Patch** (for example, 1.0.1): fixes, config changes, and small corrections.
- **Minor** (for example, 1.1.0): new content or meaningful additions that remain compatible with the current pack direction.
- **Major** (for example, 2.0.0): major pack changes or a breaking overhaul.
